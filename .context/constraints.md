## 🚫 硬约束（违反 = 打断/回滚）

1. **安全最高优先级** — 不执行危险命令、不硬编码密钥、不跳过验证
2. **改代码前先 grep** — 确认影响面，删代码前确认无引用
3. **压缩前必写 checkpoint** — 更新 `.context/handoff.md`，精确值必须写文件
4. **涉及系统修改先出方案** — 等确认后执行，不擅自改配置/删文件/装东西
5. **做完就验证** — 跑测试、查日志，不靠猜
6. **每次改动加注释** — 解释为什么这样做，不描述代码做什么
7. **涉及时效性判断必须先 WebSearch** — 不依赖训练数据中的价格/版本/日期
8. **用户说停/不对/换方向 → 立即停** — 不辩解，重新理解

## ⚡ 效率规则

- 100K token 主动 compact，不等炸了才压
- 搜索/审查派 subagent，脏活不占主上下文
- 独立任务并行派发
